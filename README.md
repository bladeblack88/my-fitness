# МОЙ ФИТНЕС

Красочное адаптивное приложение для домашних тренировок на 4 недели.

## Запуск
Откройте `index.html` в браузере. Никаких сборщиков, серверов или зависимостей не требуется.

## Возможности
- План из трёх занятий в неделю на четыре недели.
- Карточки упражнений с авторскими SVG-схемами.
- Отметки выполнения с сохранением в localStorage.
- Запись веса, отжиманий, подтягиваний и заметок.
- Адаптивный тёмный дизайн для телефона и компьютера.

## Публикация через GitHub Pages
В репозитории откройте **Settings → Pages**. В разделе Build and deployment выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и нажмите Save. После публикации сайт будет доступен по адресу:
https://bladeblack88.github.io/my-fitness/

> Программа является общим стартовым шаблоном, не медицинским назначением. При боли, головокружении или необычной одышке прекратите тренировку. Усложняйте нагрузку только при уверенной технике и хорошем самочувствии.
