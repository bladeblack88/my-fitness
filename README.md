# MY FITNESS

Универсальное адаптивное приложение для тренировок. Каждый пользователь создаёт отдельный профиль и ведёт собственную историю.

## Возможности
- Несколько локальных профилей на одном устройстве.
- Анкета: цель, опыт, возраст, рост, вес, доступное оборудование, частота и длительность занятий, ограничения.
- Тренировочные карточки с анимированными SVG-иллюстрациями.
- Отдельный таймер упражнения и таймер отдыха для каждого упражнения.
- Запись фактических повторений/времени и журнал тренировок.
- Недельный обзор с рекомендациями: осторожно повысить, сохранить или снизить нагрузку.
- Напоминания о воде и тренировках через уведомления браузера.
- Адаптивный неоновый интерфейс для телефона и компьютера.

## Запуск и публикация
Откройте `index.html` в современном браузере. Для публикации через GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

Адрес проекта: https://bladeblack88.github.io/my-fitness/

## Важно о данных и уведомлениях
- Профили и история сохраняются в localStorage этого браузера и устройства. Это не облачная синхронизация: для разных устройств или совместного доступа потребуется серверная база данных и авторизация.
- Напоминания браузера срабатывают, пока страница приложения открыта. Для уведомлений при закрытом браузере понадобится подключить push-инфраструктуру и service worker.
- На общем устройстве переключайтесь на свой профиль и не сохраняйте чувствительную информацию.

## Безопасность тренировок
План — общий стартовый шаблон, а не медицинское назначение. Увеличивайте нагрузку постепенно, только при хорошей технике и восстановлении. При боли или необычных симптомах прекратите провоцирующее упражнение и при необходимости обратитесь к медицинскому специалисту.
